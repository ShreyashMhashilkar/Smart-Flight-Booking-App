
A full-stack smart flight booking app that allows users to search, book, and manage flights easily — powered by React.js (frontend), Django REST Framework (backend), and Machine Learning for flight price prediction.

**Features**

Flight search and booking <br>
User authentication (JWT)<br>
Seat selection and booking management<br>
AI-powered flight price prediction<br>
Responsive and modern UI<br>

**Tech Stack**<br>

Frontend: React.js, Material UI, Framer Motion, Axios<br>
Backend: Django REST Framework, Python, SQLite<br>
Machine Learning: Scikit-learn, Pandas, NumPy<br>

**Setup Instructions**<br>
**Backend**<br>
cd flight_booking_backend<br>
pip install -r requirements.txt<br>
python manage.py migrate<br>
python manage.py runserver<br>

**Frontend**<br>
cd flight_booking_frontend<br>
npm install<br>
npm start<br>


Open http://localhost:3000<br>
 in your browser to view the app.<br>


**Frontend Overview (React.js)**<br>

The React.js frontend provides an intuitive interface for users to:<br>
<br>
Search and display available flights<br>
Select seats and confirm bookings<br>
Login/register with JWT authentication<br>
View and manage previous bookings<br>
